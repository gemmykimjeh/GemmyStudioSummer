**Baseline selection — 3 confirmed conditions (all must be satisfied):**

**① Code clone is a must.** Both the agent code AND the benchmark-test adapter code must be identically git-clonable (git clone/pull). Not just the agent — the adapter that runs it on a specific benchmark too.

**② Commercial-first.** Pick a commercial agent. If you want to pick a paper instead, that paper is valid only when — upon dissecting the structure of a commercial agent available on the market — a similar structure is found in it.

**③ Domain fit.** The test you intend to clone may not have been run on a benchmark in our benchmark set. But if the domain overlaps — i.e., testing on that benchmark points in the same direction as building our commercial agent — then running that benchmark test is allowed. Otherwise, exclude it.
