        - When TB2 runs, it opens a “container” to run specific tasks and exits the container with result after the tasks. Then, with the result, they grades if agent has success or not.
        - For ACE to learn something, ACE has to update playbook. But for ACE to learn something from signal, the signal has to be based on right or wrong which is resulted after the container is closed.
