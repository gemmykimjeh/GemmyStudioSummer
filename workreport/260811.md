Error Analysis

- Category B. They know the answer but don’t know how the answer should be presented or parsing error.

- Category D. Numbers are wrong — Most of them are this type.

- Category E. Not random but close answers.
- Category F. Wrong list. Every item has to be right.
- We have to prevent these categories without having any overfitting or benchmark specific module/instruction/prompt changes.

Agent Behavior-wise

- If agent runs single task for more than 20 steps, it usually fails. The successful rate becomes flat after 20+ steps.
- I think the reason is we don’t have any verifying steps to see if the answer is correct.
    - Agent stops searching for answers when they think they have an answer, not if they think they have a reason.
- Also, agent admits if they fail and use hedge (risk-avoidant) expressions.
- For counting problems, they don’t know if they’ve seen enough.

Harness-wise
