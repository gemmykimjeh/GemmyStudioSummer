- More paper review to strengthen feedback loop — Jehyung’s feedback loop idea 1, Jehyung’s feedback loop idea 1 simplified
    - ReasoningBank — ReasoningBank, https://arxiv.org/abs/2509.25140
        - This paper proposes agent can extract inference strategy from its experience (including failures), and can be used in next task for better performance.
        - We can use the fact that from failures, we can extract lessons (abstract) or “what not to do” rules and add it to our playbook. Before this, we learned playbook only by successful behaviors.
    - Self-Grounded Verification — Self-Grounded Verification, https://arxiv.org/abs/2507.11662
        - If we just let LLM to judge whether the task is done great or poor, they tend to give way too generous evaluations. This paper proposes self-grounded verification makes the checklist prior to the task perform by just looking at the task. To make sure the checklist is relevant to the task, the checklist should be grounded to task itself and lower the parameter, create checklist multiple times and compare each other.
        - We have GDPval as our benchmark set, which does not have ground-truth/task indicator, so reflector doesn’t learn anything.
